# UDF Common V2 migration

Independent read-only ECMA-167/UDF candidate. Single type-1 physical
partition, paired descriptor sequences, CRC and tag checks, closed
integrity state, FE/EFE, short/long/inline allocation descriptors,
bounded allocation continuations, UTF-8 decoded CS0 names, sparse
regular-file reads, local symbolic-link components. The same provider
source builds the hosted carrier and import-free AMD64 firmware ELF.

CI uses independently generated UDF 1.02 optical media rather than
mounting a kernel filesystem. Other UDF revisions and descriptor
variants require separate qualification. Virtual/sparable/metadata
partition maps, multiple partitions, VAT, writable or open integrity
state recovery, full ownership reconciliation, formatting, mutation,
defragmentation and release are outstanding.
